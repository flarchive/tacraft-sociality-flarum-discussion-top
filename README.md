# Discussion Top for Flarum

Open Flarum discussions from the first post instead of automatically jumping to the latest reply.

## Features

- Open discussions from the first post when clicking topics in the discussion list
- Keep direct links to specific posts working as expected
- Simple and lightweight, with no additional configuration required

## Installation

```bash
composer require tacraft-sociality/flarum-discussion-top
php flarum cache:clear
```
